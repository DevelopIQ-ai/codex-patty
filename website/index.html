FAQ

      

        

          
            What is Pattystack?
            
          
          

            Pattystack is a local daemon that signs into multiple Codex or OpenAI-compatible subscriptions and routes each request to the sub with the most available quota. It's one endpoint for all the subscriptions you already pay for.
          

        


        

          
            How is this different from the official OpenAI API?
            
          
          

            You bring the subscriptions, Pattystack brings the routing. It runs on your machine or tailnet, routes to the cheapest available sub, and can fall back to paid API credits only when all your subs are exhausted.
          

        


        

          
            Does it work with Claude Code / Cursor?
            
          
          

            Yes. Point any client that supports a custom OpenAI-compatible endpoint at http://127.0.0.1:3210/v1 and use the API key printed at startup.
          

        


        

          
            Is my data private?
            
          
          

            By default Pattystack binds to 127.0.0.1, so only the machine it's running on can reach it. Prompts and responses are not sent to any third party beyond the provider you route to.
          

        


        

          
            What subscriptions can I stack?
            
          
          

            Any OpenAI-compatible provider. The primary use case is Codex app-server subscriptions and personal ChatGPT/Plus accounts, but you can also add OpenAI, Anthropic-compatible proxies, vLLM, or Ollama endpoints.
